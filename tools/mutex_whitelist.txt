# Subsystem public-mutator whitelist.
#
# The mutex contract forbids public state-mutating access functions on
# Subsystem subclasses (the mechanisms instantiated by Robot / its composites).
# Those belong package-private, behind a RobotAction. This file lists the
# sanctioned exceptions, one per line, as `ClassName::methodName`.
#
# A whitelisted function should be fail-safe (lock-aware: checks isLocked() /
# returns false while locked) or a configuration-type setter. It must NOT be a
# state-changing or functionality-affecting call that bypasses the mutex.
#
